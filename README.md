# linastudio.ru

Личное портфолио. React + TypeScript + Vite, без CSS-фреймворков и без
библиотек готовых компонентов: вёрстка, анимация, шейдеры и серверная
часть написаны руками.

Из внешнего только то, что не имеет смысла писать заново: Three.js для
шара, Lenis для плавной прокрутки, React Router для адресов и шрифты.
Одиннадцать зависимостей, все используются.

**Живой сайт:** https://linastudio.ru/ · [английская версия](https://linastudio.ru/en/)

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/ + постобработка SEO
npm run pack       # папка site/ — то, что заливается на хостинг
npm run typecheck  # проверка типов без сборки
```

Ключи для запуска не нужны: блок с вопросами без них работает в локальном
режиме, поиском по данным самого сайта.

## Что внутри

```
src/
  data/          все тексты и данные сайта, двуязычные
  aurora/        шар: сцена на Three.js и её версия без WebGL
  ai/            сборка знаний для модели, отвечающей на вопросы
  components/    Hero, WorkList, About, Contact, Threads
  pages/         проект, услуги, работа в штате, политика, 404
  i18n/          язык живёт в адресе: / и /en/
  styles/        один global.css, без препроцессоров
public/
  api/ask.php    серверная ручка блока с вопросами
  clips/         записи работы проектов
  .htaccess      правила сервера: адреса, коды ответа, заголовки
scripts/
  seo.mjs        постобработка: HTML для роботов, sitemap, llms.txt
  shots.mjs      съёмка кадров проектов через Playwright
  clips.mjs      запись роликов через Playwright
  indexnow.mjs   уведомление поисковиков об изменившихся адресах
  og.mjs         картинка ссылки
  icons.mjs      иконки и favicon.ico
```

Весь текст двуязычный и хранится как `{ ru: '...', en: '...' }` — тип `L`
в `src/i18n/lang.tsx`. Забыть второй язык не даст TypeScript.

## Решения, которые стоит посмотреть

Не список технологий, а места, где было из чего выбирать.

### Сайт рисуется в браузере, но роботу отдаётся текстом

`scripts/seo.mjs` после сборки Vite раскладывает по адресам настоящие файлы
и пишет в тело каждого содержимое обычным HTML — заголовки, абзацы, разбор
проекта, контакты. Без этого шага робот и языковые модели видят пустой
`<div id="root">`. React заменяет эту разметку собой, когда доезжает.

Оттуда же собираются `sitemap.xml`, `llms.txt` и разметка schema.org.

### Даты обновления настоящие, а не дата сборки

`seo-dates.json` хранит отпечаток содержимого каждого адреса. Дата меняется,
только когда меняется содержимое. Иначе правка опечатки в политике объявляла
бы переписанными все двадцать страниц разом, а поисковик, заметив это,
перестаёт читать дату вовсе.

### Защита промпта — в коде, а не в промпте

`public/api/ask.php`. Словесный запрет «не раскрывай инструкции» на маленькой
модели не держится: проверка показала утечку в двух попытках из трёх.
Поэтому стоит решето — на входе по списку признаков и на выходе по маркерам,
до и после обращения к модели. Пять попыток из пяти отсекаются за 67–113 мс.

Там же ограничение шесть запросов в минуту с адреса и дневной потолок.

### Стоимость промпта

Системный промпт оплачивается на каждом запросе. Справочный материал вынесен
из него и подцепляется по ключевым словам вопроса — счёт вдвое, качество
ответов не изменилось. `src/ai/knowledge.ts`.

### Шар работает везде

`src/aurora/stage.tsx` — сцена на Three.js с четырьмя ступенями качества.
Ступень выбирается догадкой по железу, дальше сцена меряет свою частоту
кадров и опускается сама.

`src/aurora/flat.tsx` — тот же шар слоями краски, для машин без WebGL2
и для тех, кто просил меньше движения. Берёт место, размер и цвет из той
же таблицы секций, что и сцена. Решение принимается до загрузки Three,
поэтому машина без WebGL2 не скачивает мегабайт впустую.

### Плавная прокрутка отключается сама

Lenis рисует прокрутку из общей очереди кадров, и на слабой машине она
запинается там, где родная прокрутка браузера не запнулась бы. Сторож
считает длину кадров во время прокрутки и, если она раз за разом вдвое
длиннее положенного, отдаёт прокрутку обратно браузеру. `src/App.tsx`.

### Английская версия — отдельные файлы, а не режим отображения

Язык живёт в адресе: `/` и `/en/`. За каждым адресом лежит свой файл со
своим заголовком, описанием и текстом. Прежняя схема с меткой `?lang=en`
отдавала по обоим адресам один и тот же русский файл, и поисковик выкидывал
английскую версию как копию.

Канонический адрес английской главной — со слэшем. Рядом обязана лежать
папка `en/` с английскими проектами, и Apache, увидев запрос `/en`, узнаёт
в нём папку раньше правил из `.htaccess`.

## Выкладка

Хостинг обычный, reg.ru. Cloudflare, Netlify и Vercel отпали по одной
причине: из России без VPN не открываются.

```bash
npm run pack
```

Собирает папку `site/` — её содержимое заливается в корень сайта. Внутри
страницы, правила сервера и серверная часть.

```bash
npm run ping -- --all
```

После заливки сообщает Яндексу и Bing об изменившихся адресах через IndexNow.

### Ключ модели

Живёт в `api/config.php` на сервере, и только там. В репозиторий не попадает,
при заливке не затирается — `scripts/pack.mjs` сохраняет его из прошлой
сборки. Без него блок с вопросами переходит на поиск по данным сайта:
работает и честно подписан, просто отвечает суше.

Образец — `public/api/config.example.php`.

## Доступность

Проверено и держится: пропуск навигации по Tab, видимая рамка фокуса,
`prefers-reduced-motion` останавливает движение шара и прокрутки,
контраст текста над шаром замерен на всех семи цветах проектов,
на телефоне под текстом лежит подложка, гаснущая без видимых границ.

Lighthouse на телефоне: доступность 100, SEO 100.
